# Clinical Trials Data Cleaning & Analysis

## Project Overview
This project demonstrates the use of Python to clean, organize, and analyze a synthetic clinical trial dataset. The goal was to explore participant information, treatment groups, adverse events, completion status, and data quality across clinical sites.

## Objectives
- Identify and standardize inconsistent data entries.
- Identify missing biomarker measurements.
- Clean categorical variables for consistent analysis.
- Summarize adverse events by treatment group.
- Analyze participant completion rates.
- Evaluate missing biomarker data across clinical sites.
- Create visualizations to communicate findings.

## Tools & Technologies
- Python
- pandas
- Matplotlib
- Google Colab
- GitHub

## Data Cleaning
The dataset contained inconsistent category labels and missing biomarker measurements. I standardized sex, treatment, and completion-status categories. I also tracked originally missing biomarker measurements before filling missing values with the median.

## Analysis
The project includes:
- Participant counts by treatment group.
- Adverse-event counts and rates by treatment group.
- Participant completion counts and percentages.
- Missing biomarker data rates by clinical site.

## Skills Demonstrated
- Data cleaning and preprocessing
- Exploratory data analysis
- Missing-data assessment
- Grouped summaries and percentage calculations
- Data visualization
- Documentation and reproducible analysis

## Key Takeaway
This project provided hands-on practice using Python to prepare and analyze structured data, assess data quality, and communicate results through visualizations. These skills are relevant to entry-level data analysis, clinical research support, and biotechnology data management.

## Dataset Disclaimer
This project uses a synthetic dataset created for educational and portfolio purposes. It contains no real patient data and is not intended to support clinical decisions.
